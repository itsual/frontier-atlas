Simple rules that improve results

Good routing is about matching the work, not treating a model name as a permanent default.

01

Start light

Use the lowest reliable effort. It keeps interactions responsive and gives you room to step up when real complexity appears.

02

Effort is not length

Reasoning depth and response size are separate choices. Ask for the format and length you need.

03

Switch with evidence

Move to a stronger model when representative checks show a meaningful gain for your own workflow.
